## Данные

**Набор:** MNIST Variant V2
- **Обучающая выборка:** `d2.csv` — 60 000 объектов
- **Тестовая выборка:** `mnist_test.csv` — 10 000 объектов
- **Размер изображений:** 28×28 пикселей → вектор 784
- **Диапазон пикселей:** [0.0, 255.0]

### Предобработка
- **Стратифицированное разбиение:** train 51 000 / val 9 000 (seed=42)
- **Балансировка:** oversampling до размера majority класса
- **Очистка:** удаление 572 статистических аномалий (0.95%)

---

## Архитектура модели

**Двухслойный перцептрон (MLP):**
Input(784) → Linear(256) → ReLU → Dropout(p) → Linear(10) → Logits

**Параметры:**
- Обучаемые параметры: **203 530**
- Инициализация: Xavier uniform
- Функция потерь: CrossEntropyLoss (softmax внутри)
